关键发现（选品 / 上架视角）

  • 已验证的卖点：夜光/发光效果是最强记忆点（"比想象中还亮"），绿色 / 荧光绿好评集中；"这个价格太值了"被多次提及 —— Rs.855 低价位段的心智已经立住。
  • 痛点 1 · 塑料质感差（最高频）：至少 3 条明确抱怨 "plastic quality is low / very poor / 很快就断"。3D 打印 PLA/树脂件的通病，也是差评第一来源。
  • 痛点 2 · 关节松紧两极分化：有人说"关节松（loose / burul）"，也有人说"卡得紧要硬掰"。装配公差不稳定，出货无法全检 → 建议详情页写"首次拼装请稍用力/耐心"，把预期管理前置。
  • 痛点 3 · 尺寸虚标（最容易吃差评）：买家实测"标 25cm，实际约 15cm"。严重期望落差，务必在主图标注真实尺寸，或改标 15cm / 加参照物对比图。
  • 痛点 4 · 缺件 / 断件："weapons are broken"、"pieces missing"。小配件（武器件）单独包装易漏发 → 建议改一体成型，或用自封袋统一封装并附配件清单。
  • 痛点 5 · 色差 + 夜光不稳定：黄色发成橙色、黑色没图片好看、有的不发光（夜光需吸光后才亮）。建议主图用实拍，并在详情说明"需光照充能"。
  • 机会点 · 改装/替换件需求：有买家把它当替换身体装到别的机器人上（"我把原装身体换成了这个"）→ 可做"备用关节 / 配件组合包"或"双只装"提高客单价。
  • 品类判断：该品在 Daraz LK 有真实需求、价格带心智清楚，但退货/差评风险集中在材质脆 + 公差 + 尺寸虚标。若要切这个品，差异化方向应该是：换更韧的材质 + 真实尺寸标注 + 配件齐套包装 + 主图实拍夜光效果，溢价 10-20% 有空间。
