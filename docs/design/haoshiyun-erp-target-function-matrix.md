# 好时运跨境 ERP 目标功能覆盖矩阵

**范围**：把附件 V1.1 需求映射到当前 UI/UED 原型、目标业务能力、依赖决策与验收证据。
**当前状态**：UI/UED 原型阶段。所有新增原型使用浏览器端示例状态，不是已接通数据库/API 的 ERP 功能。

## 1. 能力成熟度定义

| 等级 | 定义 |
|---|---|
| D0 规格 | 已描述 IA、字段、状态与交互 |
| D1 可操作原型 | 页面可操作示例流程，刷新即复原，无后端写入 |
| D2 业务接入 | 有 API/domain/DB 持久化、权限和审计 |
| D3 验收上线 | 真实连接器/数据已验证，关键业务闭环通过业务验收 |

UI 存在或 DB 有相似表不等于 D2/D3。

## 2.1 Excel 页面字段分组核对

附件“页面功能字段”和“字段明细”中的字段应按业务实体归属，不能作为一张大表堆在列表页面。下列字段组须在对应详情/录入区域可访问：

| 字段组 | UED 入口 | 重要细节 |
|---|---|---|
| 店铺主档 | 设置 → 店铺连接 → 创建/详情/更多设置 | seller short code、主体、团队、负责人、站点、币种、时区、履约、店铺多仓、API状态、上线日期 |
| 商品/SPU | 基础资料 → 商品 SPU 详情 | 品牌、品类、材质、款式、负责人、状态、创建/停用时间、备注 |
| SKU | SPU → SKU规格 Tab | 内部SKU、颜色/代码、尺码、包装、重量/尺寸、成本、条码、状态 |
| 字典值 | 设置 → 基础数据字典 | 类型、代码、标准名称、多语言名、别名、排序、状态、引用范围 |
| Listing 变体 | 基础资料 → Seller SKU 映射 | 平台原始颜色尺码、Item ID、平台 SKU ID、售价/币种、上架状态、同步时间、映射状态 |
| 供应来源 | SKU 详情 → 供应商 Tab | 厂家款号、采购价币种、生效期、MOQ、交期、首选、状态 |
| 采购申请/单 | 采购申请/审核/采购单/收货 | 原因、SKU/数量、供应商报价、币种、预计到货、仓库、审批意见、到货/质检/入库数量 |
| 仓储库存 | 库存查询/仓库详情/流水 | 库位、实际/锁定/可用/待入库/残次、库存类型、来源单、前后数量、操作者/时间 |
| 订单明细 | 订单详情 | 店铺/站点、订单行ID、Item/SKU ID、Seller SKU、内部SKU、数量/金额/币种、付款/履约状态、时间节点、异常原因 |
| 包裹履约 | 订单详情 → 包裹与物流 | 包裹号、运单历史、承运商、履约模式、出库仓、重量、仓库出库、JSB交接、清关、尾程、签收、异常 |
| 售后/利润 | 售后详情/成本利润详情 | 退货质检、退款、采购批次成本、费用类型/来源、汇率值/日期/来源、毛利净利及明细 |
| 导入/日志 | 数据导入/系统日志/审计 | 批次号、来源文件/行号、校验、成功失败数量、重试、错误原因、修改前后值 |

## 4. 横向非功能目标

- **租户隔离**：所有业务记录按 `organization_id`；后台/页面不能绕过服务端 scope。
- **审计与不可抵赖**：业务单据/库存账本追加事件；主数据停用不删除；敏感 token/个人信息脱敏。
- **幂等与并发**：平台订单、库存事件、采购入库、导入批次有稳定 idempotency key；库存原子预留。
- **数据保留**：外部平台原始状态与内部映射状态并存，事件保留来源与时间，不以内部状态覆盖平台原始值。
- **多币种**：存储原币金额、币种；折算值带汇率日期/来源/版本。汇率未定时分币种查看，禁止直接汇总。
- **易用性**：上游主数据选择器只显示可用值，常用值自动带出并显示默认来源；异常有直接修复路径；危险操作优先可撤销/补偿。
- **原型真实性**：D1 页面一律标“示例数据”；非 D2 不显示“已同步/已保存/已审批”生产措辞。

## 5. 当前差距与下一阶段

本次完成的是 D1 交互覆盖扩展，不是 ERP 生产就绪。达到目标功能仍需按阶段落地：

1. 业务确认关键口径（审批矩阵、库存事件节点、仓库负库存、费用/汇率等）。
2. 将平台/站点/店铺/多仓/字典、商品、供应商、采购、库存流水的 UED 映射到 [haoshiyun-erp-database-schema.md](./haoshiyun-erp-database-schema.md)（目标 schema 已设计）并实现 domain service。
3. 先打通采购入库和共享库存账本；再接订单幂等、Seller SKU 映射、履约和异常恢复。
4. 实现多租户 RBAC/审计/导入服务；逐页用真实 API 替换 mock，并用完整测试订单验收。
5. 平台连接器、费用来源、汇率/利润口径、容量/备份和上线责任人通过 IT/业务验收后才可标记 D3。
