### Q04 · 同步频率与失败补偿

- **问题摘要**：订单和状态多久同步一次，失败后如何补偿？  
- **运营最低要求**：失败不能静默；支持自动重试和人工重试。  
- **开发答复（本轮已定）**：  
  - 频率原则：按各平台官方 API **允许的调用频率**执行，不超限。  
  - 订单增量默认同步间隔：**可配置 5 / 15 / 30 分钟**（产品建议默认先取 **15 分钟**，上线前可在设置改）。  
  - 失败自动重试：**最多 3 次**（仍失败则停止静默重试）。  
  - 失败后：**必须发通知**；接收人在 **配置页**设置（不得写死某一个人）。  
  - 失败在同步任务/集成日志中可见，支持人工重试，**禁止静默失败**（#29 UED：`/console/sync-tasks`、integration-log）。  
  - Schema：`integration_states`、`integration_logs`、`pending_actions`（含幂等键）。  
- **状态**：**已定** / 部分落地（原型可见失败与重试入口；生产 cron/通知通道待接）

### Q06 · 订单去重与库存幂等

### Q10 · 库位一启用 SKU（数据库强校验）

- **问题摘要**：如何从 DB 限制一个库位只能绑定一个启用 SKU？  
- **运营最低要求**：不能只靠页面提醒，保存时必须强校验。  
- **开发答复（本轮履历策略已定）**：  
  - 原型（#28）：`wms-store` 绑定库位时若已绑定其他启用 SKU则拒绝（文案「一库位一启用 SKU」）。  
  - 当前 `inventory_balances` 唯一键为 `(org, warehouseCode, binCode, variantId)`——保证「同库位同 SKU 一行」，**尚不等于**「同库位仅允许一个 variant」的部分唯一索引。

- **问题摘要**：是否写死在系统中？  
- **运营最低要求**：按平台、国家、履约和有效期配置；Lazada 与 Daraz 分别适用。  
- **开发答复（本轮已落地 · PR #36 / `a51b142`）**：  

| 项 | 已定/已实现 |
| --- | --- |
| 模板维度 | **平台 × 国家 × 履约两级**（业务履约池 + 物流形态）× **有效期** + **优先级**（允许区间重叠，解析取 priority 最高） |
| 模板类型 | 两套：`import_tax`（进口税叠）与 `platform_fee`（佣金/支付等）；测算可组合引用 |
| Lazada / Daraz | **分适用**（各自模板头）；种子含 Daraz LK 三档品类进口税 + Lazada MY 进口税占位 + 两边平台费占位 |
| 路由 / 侧栏 | `/console/fee-templates` 列表+详情；成本财务组侧栏「**费用模板**」 |
| 与计算器 | 按平台+国家+履约+asOf 解析；保存柜次成本写入 `feeTemplateVersionId` + components **快照** |
| 历史策略 | **新系统不纠结旧快照**；新保存带完整版本快照即可（C4） |
| LK 种子 | 自原 `TARIFF_PROFILES` 迁入，标「**待报关行复核**」（C7-A） |
| 数据落点 | 原型 localStorage；`packages/db` 草稿表 `fee_templates` / `fee_template_versions` |
| 设计文档 | `apps/shop/content/design/fee-templates-ued.md` |

- **状态**：**已定 / 已落地（UED 原型）** · 生产税率盖章与 tRPC 接线待后续  
- **备注**：种子税率仍标待复核，不等于财务/报关行已盖章上线。

## 3. 实现上特别不确定 / 易误读点（供人工审阅）

1. **库存唯一约束**：原型有「一库位一启用 SKU」校验，但 DB 当前唯一键是 `(仓, 库位, SKU)`，**还不是**「一库位仅一个 SKU」的部分唯一索引——上线前必须补强。  
2. **采购禁自审**：界面与 `assignApprover` 已体现；`approveAndConvert` **未**用当前登录人做硬拒绝——接 tRPC 时必须补（口径已定：服务端硬拒绝）。  
3. **平台费用/IM/券**：不得把 Lazada 已有 path 外推为 Daraz LK 已开通；广告默认按导入/人工，除非另给接口证据。  
4. **费用模板（#36）**：UED 可配 ≠ 生产税率已盖章；LK 种子仍「待报关行复核」。  
5. **JSB**：按「无公开 API → 人工/导入」推进，勿写成已对接货代接口。
