Open Shop 是面向多租户卖家的跨境电商运营数据中枢，当前 MVP 聚焦 Daraz 斯里兰卡站。

## 文档范围

- 租户端控制台：选品、待审、商品/刊登、订单、库存、成本与财务
- 平台运营后台：租户/店铺审核、同步健康、待审抽检
- OpenAPI / MCP：第三方与 Agent 接入
