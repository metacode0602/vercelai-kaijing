# Timeout Handle

Every sandbox has a **maximum lifetime**, controlled by the `timeout` setting. When the timeout expires, the sandbox is stopped. By default, a new sandbox stays alive for **5 minutes**.

<Callout type="info">
  **Timeout vs. Idle timeout — don't confuse them:**

  * **Timeout** is the maximum lifetime of the sandbox. It starts counting down from creation, regardless of activity, and always takes effect when it expires.
  * **Idle timeout** only fires when no client is connected for the configured duration.
</Callout>

## Create a sandbox with a timeout

<CodeBlockTabs>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="tab-1">JavaScript &amp; TypeScript</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-2">Python</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-3">CLI</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="tab-1">
  ```js
  import { GPURun } from 'gpurun-sandbox'

  const gpurun = new GPURun()
  const sandbox = await gpurun.sandbox.create({ timeoutMs: 60_000 })

  await sandbox.kill()
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-2">
  ```python
  from gpurun_sandbox import GPURun

  gpurun = GPURun()
  sandbox = gpurun.sandbox.create(timeout=60)

  sandbox.kill()
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-3">
  ```bash
  # Create a sandbox with a 60-second timeout (detached mode), prints the sandbox ID
  gpurun sandbox create base --timeout 60s -d
  ```

  </CodeBlockTab>
</CodeBlockTabs>

## Update the timeout

You can use `setTimeout` / `set_timeout` to reset how much longer the sandbox should stay alive.

<CodeBlockTabs>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="tab-1">JavaScript &amp; TypeScript</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-2">Python</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-3">CLI</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="tab-1">
  ```js
  import { GPURun } from 'gpurun-sandbox'

  const gpurun = new GPURun()
  const sandbox = await gpurun.sandbox.create({ timeoutMs: 60_000 })

  await sandbox.setTimeout(300_000)
  await sandbox.kill()
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-2">
  ```python
  from gpurun_sandbox import GPURun

  gpurun = GPURun()
  sandbox = gpurun.sandbox.create(timeout=60)

  sandbox.set_timeout(300)
  sandbox.kill()
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-3">
  ```bash
  # Reset the sandbox timeout to 5 minutes
  gpurun sandbox set-timeout <sandbox_id> 5m
  ```

  </CodeBlockTab>
</CodeBlockTabs>

## Lifecycle behavior

You can combine `timeout` with `lifecycle` to choose whether the sandbox is killed or paused when the timeout expires.

<CodeBlockTabs>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="tab-1">JavaScript &amp; TypeScript</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-2">Python</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-3">CLI</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="tab-1">
  ```js
  import { GPURun } from 'gpurun-sandbox'

  const gpurun = new GPURun()
  const sandbox = await gpurun.sandbox.create({
    timeoutMs: 300_000,
    lifecycle: {
      onTimeout: 'pause',
      autoResume: true,
    },
  })
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-2">
  ```python
  from gpurun_sandbox import GPURun

  gpurun = GPURun()
  sandbox = gpurun.sandbox.create(
      timeout=300,
      lifecycle={
          'on_timeout': 'pause',
          'auto_resume': True,
      },
  )
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-3">
  ```bash
  # Pause the sandbox instead of killing it when the timeout expires, and allow auto-resume
  gpurun sandbox create base --timeout 5m --on-timeout pause --auto-resume -d
  ```

  </CodeBlockTab>
</CodeBlockTabs>

If you do not pass `lifecycle`, the sandbox is killed when the timeout expires.
