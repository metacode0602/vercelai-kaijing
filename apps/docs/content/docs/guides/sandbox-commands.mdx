# Run Command

You can use the `commands.run()` method to run terminal commands inside the sandbox.

## Basic usage

Call `commands.run()` with a command string. The returned result contains the command output.

<CodeBlockTabs>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="tab-1">JavaScript &amp; TypeScript</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-2">Python</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-3">CLI</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="tab-1">
  ```js
  import { GPURun } from 'gpurun-sandbox'

  const gpurun = new GPURun()
  const sandbox = await gpurun.sandbox.create()

  const result = await sandbox.commands.run('ls -l')
  console.log(result)

  await sandbox.kill()
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-2">
  ```python
  from gpurun_sandbox import GPURun

  gpurun = GPURun()
  sandbox = gpurun.sandbox.create()

  result = sandbox.commands.run('ls -l')
  print(result)

  sandbox.kill()
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-3">
  ```bash
  # Execute a command in a running sandbox (alias: sandbox ex)
  gpurun sandbox exec <sandboxID> -- echo "hello"

  # Run in background
  gpurun sandbox exec <sandboxID> -b -- long-running-cmd

  # Set working directory / user / env
  gpurun sandbox exec <sandboxID> -c /home/user -u root -e KEY=VALUE -- ls -la
  ```

  </CodeBlockTab>
</CodeBlockTabs>

  const gpurun = new GPURun()

## Run in the background

Pass the background option to start a long-running process (such as a server) without blocking on it.

<CodeBlockTabs>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="tab-1">JavaScript &amp; TypeScript</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-2">Python</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="tab-1">
  ```js
  import { GPURun } from 'gpurun-sandbox'

  const gpurun = new GPURun()
  const sandbox = await gpurun.sandbox.create()

  await sandbox.commands.run('python3 -m http.server 3000', { background: true })

  await sandbox.kill()
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-2">
  ```python
  from gpurun_sandbox import GPURun

  gpurun = GPURun()
  sandbox = gpurun.sandbox.create()

  sandbox.commands.run("python3 -m http.server 3000", background=True)

  sandbox.kill()
  ```

  </CodeBlockTab>
</CodeBlockTabs>

## Override environment variables per command

You can override or append environment variables for a single command with the `envs` option. It applies only to that command.

<CodeBlockTabs>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="tab-1">JavaScript &amp; TypeScript</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-2">Python</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="tab-1">
  ```js
  import { GPURun } from 'gpurun-sandbox'

  const gpurun = new GPURun()
  const sandbox = await gpurun.sandbox.create()

  const result = await sandbox.commands.run('echo $LOG_LEVEL', {
    envs: { LOG_LEVEL: 'info' }, // applies only to this command
  })
  console.log(result.stdout) // info

  await sandbox.kill()
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-2">
  ```python
  from gpurun_sandbox import GPURun

  gpurun = GPURun()
  sandbox = gpurun.sandbox.create()

  result = sandbox.commands.run(
      "echo $LOG_LEVEL",
      envs={"LOG_LEVEL": "info"},   # applies only to this command
  )
  print(result.stdout)   # info

  sandbox.kill()
  ```

  </CodeBlockTab>
</CodeBlockTabs>

## Stream output

For long-running commands, pass `on_stdout` / `on_stderr` (Python) or `onStdout` / `onStderr` (JavaScript) callbacks to receive output as it is produced, instead of waiting for the command to finish. The returned result still contains the final exit code.

<CodeBlockTabs>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="tab-1">Python</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-2">JavaScript &amp; TypeScript</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="tab-1">
  ```python
  from gpurun_sandbox import GPURun

  gpurun = GPURun()
  sbx = gpurun.sandbox.connect(sandbox_id)

  result = sbx.commands.run(
      "for i in 1 2 3; do echo line $i; sleep 1; done",
      on_stdout=lambda data: print("OUT:", data, end=""),
      on_stderr=lambda data: print("ERR:", data, end=""),
  )
  print("exit code:", result.exit_code)
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-2">
  ```js
  import { GPURun } from 'gpurun-sandbox'

  const gpurun = new GPURun()
  const sbx = await gpurun.sandbox.connect(sandboxId)

  const result = await sbx.commands.run(
    'for i in 1 2 3; do echo line $i; sleep 1; done',
    {
      onStdout: (data) => process.stdout.write(`OUT: ${data}`),
      onStderr: (data) => process.stderr.write(`ERR: ${data}`),
    },
  )
  console.log('exit code:', result.exitCode)
  ```

  </CodeBlockTab>
</CodeBlockTabs>
