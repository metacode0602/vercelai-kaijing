# Your First Sandbox

## Create an Account

If you don't have a GPURun account, [sign up](https://gpurun.ai/user/register) first. For details, please refer to [Quickstart guide](/guides/quickstart).

New users can complete a quick account setup survey to receive \$100 in promotional  Sandbox credits. No credit card is required.

## Create API Key

Create an API key on the GPURun [Key Management page](https://gpurun.ai/settings/key-management) and keep it for later use.

## Install SDK

You can install the GPURun SDK by executing the following commands.

**JavaScript & TypeScript SDK**

```bash CLI icon="terminal" theme={"system"}
npm i gpurun-sandbox
```


**Python SDK**

```bash CLI icon="terminal" theme={"system"}
pip install gpurun-sandbox
```


## Configure Environment Variables

Create a `.env` file in your project folder if it does not exist, and configure your API key.

The SDK reads `GPURUN_API_KEY` from the environment. `dotenv/config` in JavaScript and `load_dotenv()` in Python only load the value into the process environment; you do not need to pass the API key into each example manually.

**.env**

```text Output icon="code" theme={"system"}
GPURUN_API_KEY=sk_*** # GPURun API key obtained from previous steps
```


Or you can configure the API key by setting an environment variable in your terminal.

```bash CLI icon="terminal" theme={"system"}
export GPURUN_API_KEY=sk_*** # GPURun API key obtained from previous steps
```


## Start a Sandbox with the SDK

Below is a simple example showing how to create a sandbox, execute code inside it, and list files in the sandbox filesystem.

<CodeBlockTabs>
  <CodeBlockTabsList>
    <CodeBlockTabsTrigger value="tab-1">JavaScript &amp; TypeScript</CodeBlockTabsTrigger>
    <CodeBlockTabsTrigger value="tab-2">Python</CodeBlockTabsTrigger>
  </CodeBlockTabsList>
  <CodeBlockTab value="tab-1">
  ```js
  // index.ts
  import 'dotenv/config'
  import { GPURun } from 'gpurun-sandbox'

  async function main() {
    const gpurun = new GPURun()
    const sandbox = await gpurun.codeInterpreter.create()
    try {
      const execution = await sandbox.runCode('print("hello world")')
      console.log(execution.logs)

      const files = await sandbox.files.list('/tmp')
      console.log(files)
    } finally {
      // Close sandbox when no longer needed
      await sandbox.kill()
    }
  }

  main().catch((err) => {
    console.error(err)
    process.exit(1)
  })
  ```

  </CodeBlockTab>
  <CodeBlockTab value="tab-2">
  ```python
  # main.py
  from dotenv import load_dotenv
  from gpurun_sandbox import GPURun

  # The .env file should be located in the project root directory
  # dotenv will automatically look for .env in the current working directory
  load_dotenv()

  gpurun = GPURun()
  sandbox = gpurun.code_interpreter.create()
  try:
      execution = sandbox.run_code("print('hello world')")
      print(execution.logs)

      files = sandbox.files.list("/tmp")
      print(files)
  finally:
      # Close sandbox when no longer needed
      sandbox.kill()
  ```

  </CodeBlockTab>
</CodeBlockTabs>

Execute the following commands to run the code.

**index.ts**

```bash CLI icon="terminal" theme={"system"}
npx tsx ./index.ts
```


**main.py**

```bash CLI icon="terminal" theme={"system"}
python main.py
```
