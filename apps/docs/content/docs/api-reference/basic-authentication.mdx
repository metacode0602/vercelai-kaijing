# Authentication

The `GPURun AI` API uses API keys in the `request headers` to authenticate requests. You can view and manage your API keys in [settings page](https://gpurun.ai/settings/key-management?utm_source=getstarted).

```js theme={"system"}
{
    "Authorization": "Bearer {{API Key}}"
}
```
