# User Balance Info

## Request Headers

<ParamField header="Content-Type" type="string" required={true}>
  Enum: `application/json`
</ParamField>

<ParamField header="Authorization" type="string" required={true}>
  Bearer authentication format, for example: Bearer \{\{API Key}}.
</ParamField>

## Response Parameters

<ResponseField name="availableBalance" type="string" required={false}>
  The user's credit balance, unit is 1/10000 USD (e.g., `10000` = \$1.00).
</ResponseField>

<ResponseField name="cashBalance" type="string" required={false}>
  The remaining balance of your top-up, unit is 1/10000 USD (e.g., `10000` = \$1.00).
</ResponseField>

<ResponseField name="creditLimit" type="string" required={false}>
  Your credit limit (i.e., the maximum amount you can owe), unit is 1/10000 USD (e.g., `10000` = \$1.00).
</ResponseField>

<ResponseField name="pendingCharges" type="string" required={false}>
  Pending charges, unit is 1/10000 USD. Currently defaults to `0`.
</ResponseField>

<ResponseField name="outstandingInvoices" type="string" required={false}>
  The amount you currently owe, unit is 1/10000 USD (e.g., `10000` = \$1.00).
</ResponseField>
