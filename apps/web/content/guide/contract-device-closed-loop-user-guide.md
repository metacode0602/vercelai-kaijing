# 合同流转 + 设备流转闭环操作手册

> **版本**: 1.0  
> **日期**: 2026-09-26  
> **适用读者**: 平台运营/商务（`apps/web`）、供应商商务/运维（`apps/supplier`）  
> **基线**: `develop-gpus`（含 #29 运营侧可发现性与合同编辑）  
> **范围**: 合同创建 → 发确认 → 供应商确认/驳回 → 生效 → 设备批次 → 审核 → 上架；网关仅「手动配置」  
> **明确不做**: GW-P1～P5 网关产品能力、品牌站 fork

---

## 0. 闭环总览

```
运营创建合同（含产能行 + 站点 BOM GW-P0）
  → 运营「发送给供应商」
  → 供应商确认 / 请求修改 / 拒绝
  → 合同生效（active）
  → 供应商创建批次（必须选择合同）并上传设备清单
  → 运营在批次详情审核设备
  → 自动/策略上架（已有流水线）
  → 网关：按 BOM 手动登记管控节点，平台审核（非 P1–P5）
```

任一步均应走真实 tRPC，不应依赖 mock。供应商门户部分设置页仍可能残留 mock 标签数据，**与本合同/设备主路径无关**。

## 1. 运营侧（`apps/web`）

### 1.1 创建合同

1. 登录运营后台，侧栏进入 **供应商 / 合同**（路径大致为 `/supplier/contracts`）。
2. 点击 **新建合同**。
3. 填写：
   - 供应商、合同类型、合作模式（闲时 / 整租）、计价方式与价格字段
   - **产能明细**：机房 + GPU 卡型 + 设备数/GPU 数 + 起止日期（至少一行）
   - **站点 BOM（GW-P0）**：规模分档、精确台数、产品线、公网 IP 数、是否提供 CPU 主机
4. 保存后进入合同详情（状态一般为 `draft`）。

### 1.2 发送给供应商

1. 打开合同详情。
2. 确认产能明细非空，且站点 BOM 已按商务约定填写。
3. 点击 **发送给供应商**。
4. 状态变为 `pending`（待确认）；供应商门户可见该合同。

### 1.3 供应商反馈后的处理

| 供应商动作 | 合同状态 | 运营动作 |
|-----------|---------|---------|
| 确认 | `active` | 可进入设备批次审核；可手动关联设备 |
| 请求修改 | 回到 `draft`，带修改意见 | 编辑合同后再次发送 |
| 拒绝 | `rejected` | 可编辑后再次发送，或终止流程 |

编辑入口：详情页 **编辑**（对接真实 `supplier.contract.update`，含 BOM/产能行）。

### 1.4 查看产能与 BOM

合同详情中：

- **产能明细**：展示机房名称、卡型名称（非裸 ID）。
- **站点 BOM（GW-P0）**：只读展示分档/产品线/公网 IP 等，可下载 BOM Excel。
- **已关联设备**：列表展示；生效合同可点 **关联设备 / 手动关联**。

### 1.5 手动关联设备（补录）

适用：历史设备未随批次写入 `contractId`，或需要把孤儿设备挂到合同。

1. 打开 **生效中** 合同详情。
2. 点击 **关联设备**。
3. 在对话框中勾选「尚未关联合同」的设备，确认关联。
4. 列表刷新；设备 `contractId` 写入当前合同。

批次正常提交时会自动写入合同关联，无需重复手动操作。

### 1.6 审核设备批次

1. 侧栏进入上架批次 / 在线任务等相关列表（如 `/supplier/online-tasks` 或批次详情入口）。
2. 打开批次详情，使用 **设备审核** 面板：批量通过 / 驳回。
3. 审核通过后，按已有自动上架/策略引擎进入市场可见（以环境配置为准）。

### 1.7 网关节点审核（手动配置）

1. 侧栏打开 **网关节点审核**（`/supplier/gateway-nodes`）。
2. 审核供应商提交的管控节点：通过 / 拒绝。
3. **注意**：这只是手工登记 + 审核，**不是** GW-P1～P5 自动化产品。

### 1.8 终止合同

生效合同详情可 **终止合同**（需填写原因）。终止后不可再新建关联批次或关联设备。

## 2. 供应商侧（`apps/supplier`）

### 2.1 确认合同

1. 登录供应商门户 → **合同**（`/console/contracts`）。
2. 打开待确认合同（`pending`）。
3. 核对：产能明细（机房/卡型名称）、合作模式、站点 BOM（GW-P0）。
4. 操作其一：
   - **确认合同** → 合同生效
   - **请求修改** → 填写意见，退回运营草稿
   - **拒绝合同** → 填写原因

价格敏感字段已按角色脱敏（商务可见分成等，运维更严格）。

### 2.2 站点 BOM 只读说明

合同详情含 **站点 BOM（GW-P0）** 只读区。页面会提示：

> 网关自动化（GW-P1～P5）尚未上线；请按 BOM 在「网关」菜单手动配置管控节点，并等待平台审核。

### 2.3 创建设备批次（必须选合同）

1. 合同生效后，可在合同详情点 **创建关联批次**，或进入 **设备 → 批次 → 新建**。
2. **关联合同 \***：下拉仅列出生效合同（可从 URL `?contractId=` 预填）。
3. 选择机房、合作模式（默认跟随合同）、上传设备清单（xlsx/xls/csv）。
4. 解析预览 → **确认提交**。
5. 系统会：
   - 将 `contractId` 写入批次
   - 校验合同容量 120% 上限
   - 提交设备时写入设备 `contractId`
6. 批次进入待审核/待接入队列，等待运营审核。

未选合同无法创建批次。

### 2.4 网关手动配置

1. 进入 **网关**（`/console/gateways`）。
2. 页面顶部有手动配置说明（P1–P5 未上线）。
3. **注册网关节点**：按向导填写机房、主机信息、SSH、网络。
4. 提交后等待平台 **网关节点审核**。
5. 按合同 BOM 准备：管控主机台数、公网 IP（建议 3–5）、是否自备 CPU 主机等。

## 3. 网关「手动配置」与 GW-P1～P5 边界

| 能力 | 状态 | 本闭环如何做 |
|------|------|--------------|
| GW-P0 站点 BOM 录入/展示 | ✅ 已交付 | 合同创建/详情 |
| 手动登记网关节点 + 平台审核 | ✅ 可用 | 供应商网关菜单 + 运营审核页 |
| GW-P1 自动发现/注册 | ❌ 未上线 | 不做，不假装完成 |
| GW-P2 配置下发/激活 | ❌ 未上线 | 线下/手工配合 |
| GW-P3 健康探针自动化 | ❌ 未上线 | — |
| GW-P4 对象存储代理等 | ❌ 未上线 | — |
| GW-P5 其余网关产品化 | ❌ 未上线 | — |

成功标准：**合同+设备**主路径可按本手册手工走通；网关仅手动配置；**不得**宣称 P1–P5 已完成。

## 4. 走通检查清单（验收）

- [ ] 运营新建合同（含产能 + BOM）→ 发送成功
- [ ] 供应商确认 → 合同 `active`
- [ ] 供应商建批必选合同 → 提交后批次/设备带 `contractId`
- [ ] 运营批次详情可审核设备
- [ ] 运营合同详情产能显示机房/卡型**名称**；供应商详情同理
- [ ] 供应商合同详情可见站点 BOM
- [ ] 运营可对生效合同手动 **关联设备**
- [ ] 供应商可手动注册网关，运营可审核；UI 标明 P1–P5 未上线
